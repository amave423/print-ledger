# Мастерская — учёт 3D-печати

Заказы, катушки пластика, допы и окупаемость принтера. Работает с телефона и компьютера, данные хранятся в Supabase.

- **Главная** — окупаемость (всё полученное от клиентов против всех трат), прибыль за месяц, остатки пластика.
- **Заказы** — что печатали, для кого, вес, брак, время печати, предоплата. Чистая прибыль считается с учётом пластика и электричества.
- **Пластик** — каждая катушка отдельно. Заказ списывает граммы с самой старой подходящей катушки.
- **Допы** — сопла, запчасти, инструменты.
- **Настройки** — принтеры, цена кВт·ч, пресеты температур, выгрузка в Excel.

Электричество считается примерно: по температурам сопла, стола и камеры и по времени печати.

## Запуск

1. Создайте проект на [supabase.com](https://supabase.com).
2. **SQL Editor** → выполните [`supabase/schema.sql`](supabase/schema.sql).
3. **Authentication → Users → Add user**: почта и пароль для входа. Затем **Authentication → Sign In / Providers** → выключите *Allow new users to sign up*, чтобы больше никто не мог зарегистрироваться.
4. **Project Settings → API**: впишите *Project URL* и *anon public key* в [`js/config.js`](js/config.js).
5. Перенос старой таблицы (по желанию):
   ```
   pip install openpyxl
   python tools/import_xlsx.py "отработка принтера.xlsx"
   ```
   Появится `seed.sql`. Выполните его в SQL Editor. Файл содержит ваши данные и в репозиторий не попадает.

Без настроек Supabase сайт открывается в демо-режиме: данные берутся из `demo-data.json`, изменения не сохраняются.

Локально: `python -m http.server` в папке проекта, затем http://localhost:8000.
